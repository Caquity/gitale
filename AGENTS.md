# Agent entry

When a user explicitly invokes a `$gitale ...` workflow, read and follow the
canonical Gitale Skill at `skills/gitale/SKILL.md`. It is the only workflow
source for init, stop, checkpoint, fork, amend, and Viewer behavior; ordinary
conversation stays outside the story tree. After a successful `$gitale init`,
follow that canonical Skill's session-level guidance for each subsequent
reply until the creator explicitly ends the Gitale creation session; a new
Agent session must initialize again.
